# 🚗 Turbo 3D

> **Juego arcade de manejo + evasión policial** inspirado en Smashy Road.
> Construido con Three.js, estilo voxel, jugable directo en el navegador.

## 🎯 Sobre el proyecto

Turbo 3D es un juego de navegador ligero diseñado para jugar en **breaks de trabajo**.

### Características
- 🏎️ **6 autos desbloqueables** con rareza (Común a Legendario)
- 🚔 **Sistema de persecución policial** con 5 niveles de wanted
- 💨 **Drift con Shift**
- 💰 **Economía progresiva**
- 🎁 **Cofres diarios y por racha**
- 🏆 **Leaderboard local**
- 🗺️ **Minimapa en tiempo real**

## 🕹️ Controles

| Tecla | Acción |
|-------|--------|
| `W` | Acelerar |
| `S` | Reversa |
| `A` / `D` | Girar |
| `Shift` | Drift |
| `Enter` | Reiniciar tras Game Over |

## 🛠️ Tecnologías

- **Three.js** — Motor 3D
- **Vanilla JavaScript** (ES6 Modules)
- **localStorage** — Guardado de progreso
- **GitHub Pages** — Hosting gratuito

## 📦 Cómo jugar localmente

1. Descarga o clona el repositorio
2. Abre `src/index.html` en tu navegador
3. ¡Listo!

> ⚠️ Requiere conexión a internet para cargar Three.js desde CDN.
